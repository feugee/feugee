# Badge icons are uploaded Assets, not a code vocabulary

A Badge's icon is an image Asset the Agency uploads, shown as-is inside a chip filled by the Badge's CMS color — deliberately not the Footer's Social Link pattern of a fixed in-code icon vocabulary. The Agency keeps full visual freedom per Badge; the cost is that an uploaded image cannot be tinted, so the color paints only the chip behind the icon and legibility on it is the Agency's call (the icon field's description nudges toward transparent artwork).
